2.6 Команды проверки

После завершения настройки сетевой инфраструктуры выполняется проверка корректности конфигурации. Ниже приведены основные команды диагностики в Cisco Packet Tracer.

Проверка VLAN
show vlan brief

Отображает сводную таблицу всех настроенных VLAN с идентификаторами, именами и активными портами. Подтверждает корректную сегментацию сети.

Проверка trunk-соединений
show interfaces trunk

Выводит порты в режиме trunk с разрешёнными и активными VLAN. Подтверждает правильную передачу тегированного трафика между коммутаторами.

Проверка IP-интерфейсов (SVI)
show ip interface brief

Отображает состояние всех IP-интерфейсов. Статус «up/up» у SVI-интерфейсов подтверждает работу межвлановой маршрутизации.

Проверка таблицы маршрутизации
show ip route

Выводит таблицу маршрутизации L3-коммутатора SWM1, включая подключённые подсети (C) и статические маршруты (S). Подтверждает доступность всех сегментов.

Проверка протокола STP
show spanning-tree

Показывает состояние STP для каждого VLAN. Подтверждает, что SWM1 является корневым мостом (Root Bridge) и резервные линии в состоянии Blocking.

Проверка текущей конфигурации
show running-config

Выводит полную конфигурацию устройства в оперативной памяти: VLAN, интерфейсы, протоколы и маршруты.

Проверка связи
ping [IP-адрес назначения]

Проверка сетевой связности по ICMP. Результат «Success rate is 100 percent» подтверждает корректность маршрутизации между VLAN-сегментами.

Проверка таблицы ARP
show arp

Отображает таблицу соответствия IP- и MAC-адресов активных узлов. Применяется при диагностике проблем с разрешением адресов.
