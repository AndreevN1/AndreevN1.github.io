4 ТЕХНОЛОГИИ ВЕБ

21HTML-страница
2меню навигации

Стек технологий

  • HTML5 — семантическая разметка, 21 страница пояснительной записки
  • CSS3 — Flexbox-вёрстка, CSS-переменные, медиазапросы (1200/1024/768px)
  • JavaScript — прогресс-бар чтения, подсветка меню по клику, сохранение позиции скролла

Навигация

  • Меню содержания ПЗ (левое, 270px) — полное оглавление ПЗ, 2 уровня вложенности, сохранение позиции скролла при переходах
  • Меню защита ДП (правое, 200px) — 5 разделов для защиты дипломного проекта
  • Активный пункт подсвечивается по клику пользователя

Цветовая схема

  • Тип: монохромная, основной тон — бирюзово-зелёный
  • #2F9292 — основной акцент, #07444A — тёмный фон меню, #83E3E3 — светлый акцент
  • CSS-переменные :root — единое управление палитрой из одного места

Компоновка (Flexbox)

  • Шапка: position:fixed, 92px — логотип + наименование колледжа + тема
  • Левое меню: 270px, overflow-y:auto — прокручиваемое содержание ПЗ
  • Контент: flex:1, overflow-y:auto — основная область чтения
  • Правое меню: 200px — разделы защиты ДП

Структура сайта

  • Папка site/ — 21 HTML-файл, css/style.css, js/main.js
  • Папка картинки/ — схемы L1/L2/L3, планы зданий, фасады ТКШ, логотип
  • Приложения: А — физическая схема, Б — план здания с СКС, В — кабельный журнал (60 строк)
  • Страницы защиты ДП: введение, проектная, эксплуатационная, экономическая, технология веб
