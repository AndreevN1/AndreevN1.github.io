Общая топология сети

Сеть состоит из двух филиалов — B1 (главное здание) и B2 (филиал). Каждый филиал имеет независимое подключение к интернету через своего провайдера. Между филиалами организован зашифрованный GRE-туннель поверх публичной сети с динамической маршрутизацией OSPF. Между ISP-провайдерами установлен транзитный маршрутизатор (ISP-Router), который обеспечивает IP-связность WAN-интерфейсов обоих филиалов.

  • B1: Cloud-PT (ISP1) → DSL-Modem B1.M1 → 1841 B1-R1 → ASA 5505 B1-FW1 → 3560-24PS B1-SWM1 → коммутаторы доступа B1-SW1, B1-SW2
  • B2: Cloud-PT (ISP2) → DSL-Modem B2.M1 → 1841 B2-R1 → ASA 5505 B2-FW1 → 3560-24PS B2-SWM1 → коммутаторы доступа B2-SW1, B2-SW2
  • Связь между зданиями: GRE Tunnel0 между B1-R1 (10.10.10.1) и B2-R1 (10.10.10.2) через ISP-Router

Сегментация сети — VLAN

В каждом здании применяется одинаковая структура VLAN. Межвлановая маршрутизация выполняется на многоуровневом коммутаторе SWM1 (Layer 3).

VLAN Имя Подсеть B1 Подсеть B2 Назначение
100 SERVERS 192.168.30.0/28 192.168.130.0/28 Серверный сегмент
200 USERS 192.168.40.0/27 192.168.140.0/27 Пользователи, DHCP
300 CCTV 192.168.60.0/28 192.168.160.0/28 Камеры видеонаблюдения
999 MGMT 192.168.99.0/29 192.168.199.0/29 Управление сетью, admin PC
  • ACL на VLAN200-IN: запрет USERS → CCTV, USERS → MGMT; DHCP/DNS разрешены
  • ACL на VLAN300-IN: запрет CCTV → USERS, CCTV → MGMT, CCTV → SERVERS; только ICMP наружу
  • STP: SWM1 — корневой мост (priority 24576), SW1/SW2 — резервные
  • Port Security: sticky MAC, максимум 1 адрес, violation restrict

ASA 5505 — межсетевой экран и DMZ

На каждом филиале установлен Cisco ASA 5505 с тремя зонами безопасности. DMZ реализована через no forward interface Vlan1 — стандартное ограничение лицензии Base, обеспечивающее одностороннюю изоляцию DMZ от внутренней сети.

Зона VLAN IP B1 IP B2 Security level
inside Vlan1 / Eth0/1 10.255.1.1/30 10.255.2.1/30 100
outside Vlan2 / Eth0/0 172.16.1.2/28 172.16.2.2/28 0
dmz Vlan3 / Eth0/2 192.168.10.1/28 192.168.110.1/28 50
  • NAT PAT (inside→outside): объект INSIDE-NET — весь трафик из внутренней сети маскируется за IP outside-интерфейса
  • Static NAT (dmz→outside): DMZ-SRV 192.168.10.10 ↔ 172.16.1.3 (B1), 192.168.110.10 ↔ 172.16.2.3 (B2)
  • ACL OUTSIDE-IN: разрешён входящий TCP на 172.16.x.3 по портам 80, 443, 21, 25, 110 (публикация DMZ)
  • ACL OUTSIDE-IN: разрешён трафик из сетей другого здания (для межзданийной связи через туннель)
  • Статические маршруты inside: все внутренние VLAN-подсети и сети второго здания via 10.255.x.2 (SWM1)

GRE-туннель и OSPF между зданиями

Для объединения двух филиалов настроен GRE-туннель между маршрутизаторами B1-R1 и B2-R1. Поверх туннеля запущен OSPF, который автоматически распространяет маршруты всех внутренних сетей между зданиями.

Параметр B1-R1 B2-R1
WAN-интерфейс Fa0/1: 100.64.1.2/30 Fa0/1: 100.64.2.2/30
Tunnel0 IP 10.10.10.1/30 10.10.10.2/30
tunnel source FastEthernet0/1 FastEthernet0/1
tunnel destination 100.64.2.2 100.64.1.2
OSPF router-id 1.1.1.1 2.2.2.2
OSPF network 10.10.10.0/30 area 0 10.10.10.0/30 area 0
  • OSPF redistribute static subnets — все статические маршруты перераспределяются в OSPF как External Type 2 (O E2)
  • ISP-Router обеспечивает транзитную связность: Fa0/0 (100.64.1.1/30) ↔ Fa0/1 (100.64.2.1/30)
  • Cloud-PT настроены: Modem4 ↔ Ethernet6 (DSL проброс) — трафик между DSL-модемом и Ethernet-портом в сторону ISP-Router
  • Состояние туннеля: FULL — OSPF-сосед найден, маршруты получены динамически

Маршрутизация — путь пакета между зданиями

  • Хост B1 (192.168.40.x) → B1-SWM1 (default route → 10.255.1.1) → B1-FW1 ASA outside → B1-R1 → GRE Tunnel0 → B2-R1 → B2-FW1 outside → B2-SWM1 → хост B2
  • B1-FW1 знает сети B2 через статические маршруты route outside via 172.16.1.1 (B1-R1)
  • B2-FW1 знает сети B1 через статические маршруты route outside via 172.16.2.1 (B2-R1)
  • ACL OUTSIDE-IN на обеих ASA явно разрешает трафик из подсетей противоположного здания
  • OSPF на роутерах передаёт маршруты типа O E2 — все 10 внутренних подсетей видны с обеих сторон

Результаты проверки связности

  • ✅ Внутри здания: пинг между всеми VLAN через SWM1 (inter-VLAN routing)
  • ✅ GRE туннель: B1-R1 ping 10.10.10.2 — 100% успех
  • ✅ OSPF сосед: Neighbor 172.16.2.1 (B2-R1) — состояние FULL
  • ✅ Межзданийная связь: хост B1 (192.168.40.x) ping хост B2 (192.168.140.x) — пинг проходит
  • ✅ DMZ B1 снаружи: http://172.16.1.3 открывается с ПК B2
  • ✅ DMZ B2 снаружи: http://172.16.2.3 открывается с ПК B1
  • ✅ DHCP: пользовательские ПК получают адреса автоматически
  • ⚠️ DMZ изнутри своего здания: недоступна по прямому IP — ограничение ASA 5505 Base (no forward interface Vlan1). Доступ к DMZ-сервисам своего здания реализуется через публичный IP (Static NAT)
