Общая топология

Сеть — два здания: B1 (главное) и B2 (филиал), каждое со своим провайдером. GRE-туннель с OSPF между зданиями. Внутри — L3-коммутатор SWM1, межсетевой экран ASA, коммутаторы доступа.

DMZ и особенность в Cisco PT

DMZ для публичных сервисов: HTTP, HTTPS, FTP, EMAIL. Static NAT: 172.16.1.3 (B1) / 172.16.2.3 (B2).

Особенность ASA 5505 Base: no forward interface Vlan1 блокирует прямой трафик inside→DMZ. В реальном проекте — UserGate F100 без этого ограничения.

Связность между зданиями

GRE-туннель: B1-R1 (10.10.10.1) ↔ B2-R1 (10.10.10.2). OSPF распространяет маршруты автоматически.

Реализованные сервисы

  • DHCP — автовыдача IP, VLAN 200 и 300, ip helper-address
  • DNS — corp.local → DMZ-сервер
  • NTP — синхронизация времени
  • SYSLOG — централизованный сбор логов
  • TFTP — резервное копирование конфигураций
  • HTTP/HTTPS — веб-сервер DMZ, 172.16.1.3
  • FTP — файловый сервер DMZ
  • EMAIL — SMTP/POP3 DMZ, corp.local
